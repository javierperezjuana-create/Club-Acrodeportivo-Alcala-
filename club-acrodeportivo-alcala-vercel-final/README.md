# Club Acrodeportivo Alcalá

Web preparada para publicar gratis en Vercel.

## Cómo probarla en local, opcional
Si sabes usar terminal:

```bash
npm install
npm run dev
```

## Cómo publicarla en Vercel
1. Sube todos estos archivos a un repositorio de GitHub.
2. Entra en Vercel.
3. Pulsa Add New > Project.
4. Elige el repositorio.
5. Pulsa Deploy.

Vercel detectará Vite automáticamente.
